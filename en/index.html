EGTools++

Modern Excel functions on legacy Excel

EGTools++ is a single-file .xll add-in that brings the newest Microsoft 365 functions to Excel 2010 and later. No installer, no runtime, no admin rights.

What you get

128 functions

69 modern Excel functions (lookup, dynamic arrays, text, aggregation, regex, web), 7 Google Sheets functions and 52 EGTools-only ones.

Version-adaptive names

Registers as EG.-prefixed when the host already has the native function, and under the original name when it does not — so old workbooks keep their formulas.

Dynamic-array spill

Native spill on modern Excel, automatic CSE array expansion on older versions, same result either way.

In-cell IntelliSense

Function and argument help appears as a tooltip while you type the formula, in six languages.

The EGTools ribbon tab

Copy visible cells only, merge and split cells, insert and fit pictures, batch-extract images, build calendars and schedules with holidays, labels and mail merge over SMTP, style/name/error cleanup.

Compatibility conversion

Rewrite modern function formulas across a workbook to their compatible names and back, with an automatic backup first.

One file

Statically linked, so no VC++ redistributable is needed. Uninstalling is one checkbox in the add-ins list.

Install

No admin rights needed — register it through Excel's own dialog.

  1. Download the .xll matching your Excel bitness (EGTools++64.xll for 64-bit)
  2. In Excel, go to File → Options → Add-ins
  3. Set Manage to Excel Add-ins and click Go...
  4. Browse... → pick the downloaded .xll → OK
