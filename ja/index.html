EGTools++

旧バージョンの Excel で最新関数を

EGTools++ は、Excel 2010 以降で Microsoft 365 の最新関数を使えるようにする単一ファイルの .xll アドインです。インストーラーもランタイムも管理者権限も不要です。

主な機能

関数 128 個

最新 Excel 互換 69 個(検索・動的配列・文字列・集計・正規表現・Web)、Google Sheets 互換 7 個、EGTools 独自 52 個。

バージョン適応の名前登録

ホストに組み込み関数があれば EG. 接頭辞で、なければ元の名前で登録します。旧バージョンでも数式を書き換えずに使えます。

動的配列スピル対応

最新 Excel ではネイティブのスピル、旧バージョンでは自動 CSE 配列展開で同じ結果になります。

セル内 IntelliSense

数式の入力中に関数の説明と引数のヘルプをツールチップで表示します。6 言語対応。

リボン EGTools タブ

可視セルのみコピー、セルの結合・分割、画像の挿入・セル合わせ・一括抽出、カレンダー・予定表の作成(祝日表示)、ラベル・メールマージ(SMTP 送信)、スタイル・名前・エラーの整理。

互換変換

ブック内の最新関数の数式を互換関数名へ一括変換し、元に戻せます。変換前に自動バックアップ。

単一ファイル

静的リンクなので VC++ 再頒布可能パッケージは不要です。削除はアドイン一覧のチェックを外すだけ。

インストール

管理者権限は不要です。Excel 標準のダイアログから登録します。

  1. Excel のビット数に合う .xll をダウンロード(64 ビットなら EGTools++64.xll)
  2. Excel で ファイル → オプション → アドイン
  3. 管理で Excel アドイン を選び 設定...
  4. 参照... → ダウンロードした .xll を選択 → OK
