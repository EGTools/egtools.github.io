EGTools++

구형 Excel에서 최신 함수를 그대로

EGTools++는 Excel 2010 이상에서 Microsoft 365의 최신 함수를 쓰게 해 주는 단일 .xll 추가기능입니다. 설치 프로그램도, 런타임도, 관리자 권한도 필요 없습니다.

주요 기능

함수 128개

최신 Excel 호환 69개(조회·동적배열·텍스트·집계·정규식·웹), Google Sheets 호환 7개, EGTools 고유 52개.

버전 적응 이름 등록

호스트에 내장 함수가 있으면 EG. 접두사로, 없으면 원래 이름 그대로 등록됩니다. 구버전에서 수식을 고치지 않고 그대로 씁니다.

동적배열 Spill 호환

최신 Excel에서는 네이티브 spill, 구버전에서는 자동 CSE 배열 확장으로 같은 결과를 냅니다.

셀 내 IntelliSense

수식을 입력하는 중에 함수 설명과 인수 도움말을 툴팁으로 보여 줍니다. 6개 언어를 지원합니다.

리본 EGTools 탭

보이는 셀만 복사, 셀 병합·나누기, 그림 삽입·셀 맞춤·일괄 추출, 달력·일정표 생성(공휴일 표시), 라벨·메일머지(SMTP 메일 발송), 스타일·이름·오류 정리.

호환 변환

통합 문서의 최신 함수 수식을 호환 함수명으로 일괄 변환하고 되돌립니다. 변환 전 자동 백업.

설치

관리자 권한이 필요 없습니다. Excel 내장 대화상자로 등록합니다.

  1. Excel 비트수에 맞는 .xll 다운로드 (64비트면 EGTools++64.xll)
  2. Excel → 파일 → 옵션 → 추가 기능
  3. 관리에서 Excel 추가 기능 선택 → 이동...
  4. 찾아보기... → 내려받은 .xll 선택 → 확인
